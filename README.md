# Web Application VAPT Reports

## About

This repository contains a selection of Vulnerability Assessment and Penetration Testing (VAPT) reports prepared by me during my Cyber Security Internship.

The assessments were conducted on publicly accessible web applications using a black-box testing methodology and were focused on identifying security weaknesses, misconfigurations, outdated components, and web application vulnerabilities aligned with OWASP Top 10 and industry best practices.

## Scope of Work

During the internship, I performed:

- Web Application Vulnerability Assessment
- Security Misconfiguration Testing
- HTTP Security Header Analysis
- Information Disclosure Analysis
- Session Management Review
- Authentication & Access Control Checks
- OWASP Top 10 Security Testing
- Risk Classification and Reporting
- Remediation Recommendation Development
